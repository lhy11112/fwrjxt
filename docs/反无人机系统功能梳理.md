## 1. 系统架构概览

本反无人机系统是一套完整的 **探测-决策-反制** 闭环系统，通过 UDP/TCP 二进制协议与第三方指控平台对接。系统包含以下五大功能域：

```
┌─────────────────────────────────────────────────────────────┐
│                     反无人机系统                                │
├─────────────────────────────────────────────────────────────┤
│  ┌──────────────────┐  ┌──────────────────┐                 │
│  │   1. 探测感知层     │  │   2. 反制执行层     │                 │
│  │  ┌──────────────┐ │  │  ┌──────────────┐ │                 │
│  │  │ • 无线电测向  │ │  │  │ • 干扰反制    │ │                 │
│  │  │ • 主动雷达    │ │  │  │ • GNSS诱骗    │ │                 │
│  │  │ • ID协议破解  │ │  │  │ • 导航压制    │ │                 │
│  │  │ • 多源融合    │ │  │  └──────────────┘ │                 │
│  │  └──────────────┘ │  └──────────────────┘                 │
│  └──────────────────┘                                        │
│                                                               │
│  ┌──────────────────┐  ┌──────────────────┐                 │
│  │   3. 设备管理层     │  │   4. 智能决策层     │                 │
│  │  ┌──────────────┐ │  │  ┌──────────────┐ │                 │
│  │  │ • 光电/红外   │ │  │  │ • 无人值守    │ │                 │
│  │  │ • 转台云镜    │ │  │  │ • 自动联动    │ │                 │
│  │  │ • 箱仓控制    │ │  │  │ • 白名单管理  │ │                 │
│  │  │ • 视频流      │ │  │  └──────────────┘ │                 │
│  │  └──────────────┘ │  └──────────────────┘                 │
│  └──────────────────┘                                        │
│                                                               │
│  ┌──────────────────────────────────────────────────┐       │

└─────────────────────────────────────────────────────────────┘
```

## 2. 功能分类详述

### 2.1 探测感知功能

| 功能 | 命令码 | 方向 | 说明 |
|------|-------|------|------|
| 开启/关闭目标探测 | `0x20` | 平台→系统 | 控制整个系统的探测功能启停 |
| 上传探测目标信息 | `0x60` | 系统→平台 | 上报探测到的无人机目标信息（JSON） |
| 雷达凝视目标 | `0x65` | 平台→系统 | 指定雷达锁定特定目标持续跟踪 |

**探测数据来源类型（DataType）：**
- `0` — 无线电测向目标（被动 RF 探测）
- `1` — 主动雷达目标（雷达发射接收）
- `3` — ID 协议破解目标（破解无人机通信协议获取 ID）
- `4` — 多类型融合目标（多传感器融合结果）

**探测目标的关键信息字段：**
- 位置：经度/纬度/海拔/高度/方位/距离
- 身份：无人机型号/ID/MAC地址/频点
- 行为：速度/航向/俯仰/信号带宽/调制方式
- 标记：数据类型/融合标记/是否合作目标
- 时间戳

---

### 2.2 反制执行功能

#### 2.2.1 干扰反制（射频阻断）

| 功能 | 命令码 | 方向 | 说明 |
|------|-------|------|------|
| 开启/关闭设备攻击 | `0x30` | 平台→系统 | 控制干扰设备的发射启停 |
| 设置攻击模式 | `0x31` | 平台→系统 | 返航（驱离）/ 迫降 |
| 设置攻击频段 | `0x32` | 平台→系统 | 选择干扰频段：5.8G/2.4G/900M/1.4G/5.2G |
| 切换处置目标 | `0x64` | 平台→系统 | 指定当前需要处置的具体目标 |

**干扰频段能力：**

| Bit | 频段 | 典型用途 |
|-----|------|---------|
| Bit0 | 5.8 GHz | 图传/遥控信号 |
| Bit1 | 2.4 GHz | WiFi/遥控信号 |
| Bit2 | 900 MHz | 远距离遥控信号 |
| Bit3 | 1.4 GHz | 军用/专用频段 |
| Bit4 | 5.2 GHz | 备用高频段 |

**攻击模式：**
- **返航模式（0x00）**：切断遥控/图传链路，触发无人机自动返航
- **迫降模式（0x01）**：压制 GPS 和遥控信号，迫使无人机就地降落

#### 2.2.2 GNSS 诱骗（导航欺骗）

| 功能 | 命令码 | 方向 | 说明 |
|------|-------|------|------|
| 开启/关闭 GNSS 诱骗 | `0x36` | 平台→系统 | 控制诱骗功能启停 + 诱骗类型 |
| 设置 GNSS 诱骗模式 | `0x37` | 平台→系统 | 定向驱逐/定点迫降/禁飞/导航压制 + 诱导方向 |
| 设置方位和速度 | `0x38` | 平台→系统 | 设置诱骗信号的虚拟方位和速度 |
| 开启/关闭 GNSS 诱骗联动 | `0x41` | 平台→系统 | 探测到目标后自动联动诱骗 |

**GNSS 诱骗模式体系：**

```
GNSS诱骗模式
├── 0x0000 — 定向驱逐
│   └── 诱导方式：0x0000-驱离 / 0x0001-拉近
├── 0x0001 — 定点迫降
├── 0x0002 — 禁飞区
└── 0x0003 — 导航压制
    (使无人机导航系统失效)
```

**诱骗参数：**
- 诱导方向（驱离/拉近）
- 虚拟方位（float，角度）
- 虚拟速度（float，m/s）

**系统诱骗状态（心跳返回）：**
- `0x0000` — 空闲
- `0x0001` — 驱离中
- `0x0002` — 迫降中
- `0x0003` — 导航压制中

### 2.3 设备管理功能

#### 2.3.1 设备注册与发现

| 功能 | 命令码 | 方向 | 说明 |
|------|-------|------|------|
| 获取设备列表 | `0x50` | 平台→系统 | 查询所有接入设备信息（JSON） |
| 上传设备状态 | `0x54` | 系统→平台 | 主动上报设备状态变化（JSON） |

**支持的设备类型（DeviceKind）：**

| 编码 | 设备类型 | 角色 |
|------|---------|------|
| 0 | 主动雷达探测设备 | 探测 |
| 1 | 无线电侦测设备 | 探测 |
| 2 | 光电跟踪设备 | 跟踪 |
| 3 | 红外设备 | 跟踪 |
| 4 | 干扰设备 | 反制 |
| 6 | 诱骗设备 | 反制 |
| 8 | 智能控制箱 | 辅助 |

**设备通信模式（CommunicateMODE）：**
- `1` — Socket 网络通讯（TCP/UDP）
- `2` — 串口通讯
- `3` — 相机模式（RTSP）
- `4` — WebAPI 网络通讯

**设备传感器状态（SensorStatus）：**

| 编码 | 状态 | 说明 |
|------|------|------|
| 0 | 未知操作 | 初始/未定义 |
| 1 | 发送停止指令操作 | 正在停止 |
| 2 | 设备已展开 | 就绪 |
| 3 | 设备已收拢 | 存储状态 |
| 4 | 急停按键操作 | 紧急停止 |
| 5 | 设备正在展开中 | 过渡态 |
| 6 | 设备正在收拢中 | 过渡态 |

#### 2.3.2 光电/转台控制

| 功能 | 命令码 | 方向 | 说明 |
|------|-------|------|------|
| 设置云台控制模式 | `0x10` | 平台→系统 | 光电/干扰云台的主控权设置 |
| 上级平台调度转台引导 | `0x68` | 平台→系统 | 引导转台指向指定目标 |
| 设备转台定位 | `0x71` | 平台→系统 | 设置转台水平/俯仰角度 |
| 设备云镜控制 | `0x72` | 平台→系统 | 云台8方向控制 + 变倍/变焦 |

**云台控制模式：**
- `0x01` — 光电设备与干扰设备共用云台，由光电控制
- `0x02` — 共用云台，由干扰设备控制
- `0x03` — 禁用目标与云台联动机制

**云镜控制指令：**

| 编码 | 操作 | 编码 | 操作 |
|------|------|------|------|
| 0x01 | Up（上） | 0x06 | LeftDown（左下） |
| 0x02 | Down（下） | 0x07 | RightUp（右上） |
| 0x03 | Left（左） | 0x08 | RightDown（右下） |
| 0x04 | Right（右） | 0x09 | ZoomIn（放大） |
| 0x05 | LeftUp（左上） | 0x0A | ZoomOut（缩小） |

#### 2.3.3 箱仓与物理控制

| 功能 | 命令码 | 方向 | 说明 |
|------|-------|------|------|
| 箱仓操作 | `0x80` | 平台→系统 | 定制版本，控制设备舱开/关 |
| 系统一键定位及校北 | `0x12` | 平台→系统 | 系统自我定位并校准真北方向 |

#### 2.3.4 视频流获取

| 功能 | 说明 |
|------|------|
| 设备视频流 | 通过 RTSP 直接从设备拉取视频流，地址通过 0x50 获取 |

### 2.4 智能决策功能

| 功能 | 命令码 | 方向 | 说明 |
|------|-------|------|------|
| 开启/关闭无人值守 | `0x40` | 平台→系统 | 系统自动探测 + 自动联动攻击 |

**无人值守模式工作流程：**

```
启动无人值守(0x40, 开启)
       │
       ▼
自动启动目标探测(等效0x20,1)
       │
       ▼
┌─── 循环 ──────────────────────┐
│ 传感器持续探测                  │
│       │                       │
│ 发现目标 → 识别/分类 → 定位    │
│       │                       │
│ 自动联动效应器 → 释放干扰/诱骗  │
│       │                       │
│ 持续跟踪 → 评估处置效果         │
└─────────────────────────────┘
       │
目标消失/收到停止 → 停止攻击
```

**自动联动模式：**
- **GNSS 诱骗联动**（`0x41`）：探测到目标后，自动启动诱骗设备处置
- 无人值守模式下：自动探测 + 自动攻击，无需人工干预

### 2.5 系统运维功能

#### 2.5.1 状态监控

| 功能 | 命令码 | 方向 | 说明 |
|------|-------|------|------|
| 被动式心跳 | `0xA4` | 平台→系统 | 平台轮询状态（3s间隔） |
| 主动式心跳 | `0xA6` | 系统→平台 | 系统主动上报完整状态 |
| 上传反无系统及设备状态 | `0x54` | 系统→平台 | 设备列表及状态变化上报 |

**心跳返回的综合状态信息（44字节参数）：**

```
┌─────────────────────────────────────────────────┐
│              心跳帧返回参数结构                      │
├─────────────────────────────────────────────────┤
│ Bit0 — 系统授权状态（正常/异常）                      │
│ Bit1 — 探测功能状态（停止/开启）                      │
│ Bit2 — 反制状态（未干扰/已干扰）                      │
│ Bit3 — 探测设备连接状态（异常/正常）                   │
│ Bit4 — 反制设备连接状态（异常/正常）                   │
│ Bit5 — 无人值守模式状态（关闭/启用）                   │
│ Bit6 — 诱骗设备状态（异常/正常）                      │
│ ─ 攻击倒计时 ─ 当前干扰剩余时间                       │
│ ─ 诱骗状态 ─ 空闲/驱离/迫降/导航压制                   │
│ ─ GNSS联动/模式/方式 ─ 当前诱骗配置                   │
│ ─ 禁飞区位置 ─ 纬度/经度/海拔                         │
│ ─ 迫降区位置 ─ 中心点+半径                            │
└─────────────────────────────────────────────────┘
```

#### 2.5.2 设备运维

| 功能 | 命令码 | 方向 | 说明 |
|------|-------|------|------|
| 设备预览抓图 | `0x70` | 平台→系统 | 从光电设备获取当前帧图像 |
| 通用指令 | `0x16` | 平台→系统 | 软件重启等系统管理 |
| 透传数据包 | `0x90` | 双向 | 设备私有协议透传通道 |

#### 2.5.3 安全管理

| 功能 | 命令码 | 方向 | 说明 |
|------|-------|------|------|
| 设置电磁信号白名单 | `0xC0` | 平台→系统 | 按机型/频段设置白名单，避免误击 |

## 3. 协议特征总结

### 3.1 通信模式对比

| 特性 | UDP 模式 | TCP 模式 |
|------|---------|---------|
| 默认模式 | ✅ 默认 | ❌ 可选 |
| 延迟 | 低 | 稍高 |
| 可靠性 | 无内置保证 | 有保证 |
| 应用场景 | 实时探测数据上报 | 指令下发和配置 |

### 3.2 数据上报 vs 指令下发

```
                 第三方指控平台
                 ┌────────────┐
                 │ 0xA0       │
                 └────┬───────┘
                      │
        ┌─────────────┼─────────────┐
        │ 指令下发     │              │ 数据上报
        │ (0xA0→0x10) │              │ (0x10→0xA0)
        ▼             │              ▼
  ┌──────────┐        │       ┌──────────┐
  │ 反无系统  │        │       │ 反无系统  │
  │ 0x10     │        │       │ 0x10     │
  └──────────┘        │       └──────────┘
                      │
  ┌───────────────────┴─────────────────┐
  │ 指令下发(被动)：0x20,0x30,0x31,... │
  │ 主动上报：0x60(目标),0xA6(心跳),   │
  │           0x54(设备状态)           │
  └─────────────────────────────────────┘
```

### 3.3 帧长分类

| 类型 | 最大帧长 | 命令示例 |
|------|---------|---------|
| 短指令帧 | ≤10字节 | 0x20, 0x30, 0x12, 0x40 |
| 中长参数帧 | ≤40字节 | 0xA4(被动心跳), 0x38(设方位) |
| 长 JSON 帧 | ≤64KB | 0x60(目标信息), 0x50(设备列表) |
| 超大帧 | >64KB (特殊) | 0x70(预览抓图返回) |

### 3.4 校验算法

```
校验和 = (Src_Addr + Dst_Addr + Command + ParamLen_Low + ParamLen_High + Sum(Params)) mod 256
```

## 6. 限制与约束

1. **协议耦合性**：自定义二进制协议，无标准化 REST/gRPC 接口
2. **数据量限制**：参数长度字段 16bit，单帧最大 65535 字节
3. **IP 固定**：默认指控平台 IP 固定 `192.168.175.210`
4. **无加密认证**：协议无内置加密或身份认证机制
5. **无断点续传**：大数据帧（如抓图）无分片重传机制
6. **JSON 编码开销**：目标/设备列表使用 JSON，无 protobuf 压缩
7. **单播模式**：默认点对点通信，无组播/广播支持
