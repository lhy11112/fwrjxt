## 1. 概述

本文阐述了反无人机系统与第三方指控平台之间接口协议。

---

## 2. 通信格式

反无人机系统与第三方指控平台之间使用以太网进行通讯。

| 项目 | 说明 |
|------|------|
| **通信协议** | UDP 模式（可更改为 TCP 模式，第三方指控平台为服务端，反无人机系统为客户端） |
| **指控平台 IP 地址** | `192.168.175.210` |
| **远程端口（第三方指控平台）** | `9801`（可配置修改） |
| **本地端口（反无人机系统）** | `9800`（可配置修改） |

### 帧格式

| 字节 0~1 | 字节 2 | 字节 3 | 字节 4 | 字节 5~6 | 字节 7~N+6 | 字节 N+7 |
|---------|--------|--------|--------|---------|------------|---------|
| 起始码 | 发送端地址 | 接收端地址 | 命令 | 参数长(N) | 参数 | 校验和 |

- **N >= 0**
- **起始码**：2 字节 `0xA5 0x5A` — 目的是区分帧
- **发送端地址**：1 字节，地址分配见第3节
- **接收端地址**：1 字节，地址分配见第3节
- **命令**：1 字节，干扰器指令
- **参数长度**：2 字节（低位-字节5，高位-字节6），N 有效值 0~65535
- **参数**：N 个字节，可选参数，内容视命令长度及含义而定
- **校验和**：1 字节，累加和（源地址 + 目的地址 + 命令 + 参数长度 + 参数的数据）

### 命令返回格式

执行命令后返回统一帧格式：

| 字节0 | 字节1 | 字节2 | 字节3 | 字节4 | 字节5~6 | 字节7 | 字节8 | 字节9 |
|-------|-------|-------|-------|-------|---------|-------|-------|-------|
| 0xA5 | 0x5A | Src_Addr | Dst_Addr | 0xA2 | 0x0002 | Param1 | Param2 | 校验和 |

- **Src_Addr**：信息的发起者
- **Dst_Addr**：信息的接收者
- **Param1**：下发的命令
- **Param2**：命令的执行结果 — `0xF0` 执行不成功 / `0x0F` 执行成功

> 注：除已指出返回格式外，均以此格式返回

## 5. 详细协议通讯格式

### 5.1 被动式心跳帧

> **指令**：`0xA4`  
> **频率**：3s 发送一次心跳帧，检测状态

**请求帧：**

| 字节0 | 字节1 | 字节2 | 字节3 | 字节4 | 字节5~6 | 字节7 | 字节8 |
|-------|-------|-------|-------|-------|---------|-------|-------|
| 0XA5 | 0X5A | 0xA0 | 0x10 | 0XA4 | 0x01 0x00 | Param1 | 校验和 |

- **Param1**：固定值 `0x03`

**返回帧：**

| 字节0 | 字节1 | 字节2 | 字节3 | 字节4 | 字节5~6 | 字节7 | 字节8~9 |
|-------|-------|-------|-------|-------|---------|-------|---------|
| 0XA5 | 0X5A | 0x10 | 0xA0 | 0xA2 | 0x2C 0x00 | Param1 | Param2 |

| 字节10 | 字节11~12 | 字节13 | 字节14-15 | 字节16-17 | 字节18 | 字节19-20 |
|--------|----------|--------|----------|----------|--------|----------|
| Param3 | Param4 | Param5 | Param6 | Param7 | Param8 | Param9 |

| 字节21-22 | 字节23-26 | 字节27-30 | 字节31-34 | 字节35-38 | 字节39-42 | 字节43-46 |
|----------|----------|----------|----------|----------|----------|----------|
| Param10 | Param11 | Param12 | Param13 | Param14 | Param15 | Param16 |

| 字节47-50 | 字节51 |
|----------|--------|
| Param17 | 校验和 |

**参数说明：**

| 参数 | 类型 | 说明 |
|------|------|------|
| Param1 | byte | 下发的命令 |
| Param2 | ushort (LE) | Bit0: 系统授权状态(0正常/1异常); Bit1: 系统工作状态; Bit2: 系统反制状态; Bit3: 探测设备状态; Bit4: 反制设备状态; Bit5: 无人值守模式状态; Bit6: 诱骗设备状态 |
| Param3 | byte | 干扰模式: `0x00`-返航, `0x01`-迫降 |
| Param4 | ushort (LE) | Bit0-5.8G, Bit1-2.4G, Bit2-900M, Bit3-1.4G, Bit4-5.2G; 0:未启用, 1:已开启 |
| Param5 | byte | 云台控制模式: `0x01`-光电控制, `0x02`-干扰控制, `0x03`-禁用联动 |
| Param6 | ushort (LE) | 攻击倒计时 |
| Param7 | ushort (LE) | 系统诱骗状态: `0x0000`-空闲, `0x0001`-驱离, `0x0002`-迫降, `0x0003`-导航压制 |
| Param8 | byte | GNSS 系统联动状态: `0x00`-关闭, `0x01`-开启 |
| Param9 | ushort (LE) | GNSS 诱骗模式: `0x0000`-定向驱逐, `0x0001`-定点迫降, `0x0002`-禁飞, `0x0003`-导航压制 |
| Param10 | ushort (LE) | GNSS 诱导方式: `0x0000`-驱离, `0x0001`-拉近 |
| Param11 | float | 禁飞区位置纬度 |
| Param12 | float | 禁飞区位置经度 |
| Param13 | float | 禁飞区位置海拔 |
| Param14 | float | 定点迫降区中心点纬度 |
| Param15 | float | 定点迫降区中心点经度 |
| Param16 | float | 定点迫降区中心点海拔 |
| Param17 | int | 定点迫降区半径 |

**案例：**

请求：`A5 5A A0 10 A4 01 00 03 58`

返回：`A5 5A 10 A0 A2 2C 00 A4 3A 00 00 00 00 02 00 00 00 00 00 00 00 00 00 EF 88 E1 41 75 72 E2 42 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 64 00 00 00 66`

| Param14 | float | 迫降区纬度 |
| Param15 | float | 迫降区经度 |

### 5.3 设置云台控制模式

> **指令**：`0x10`

**请求帧：**

| 字节0 | 字节1 | 字节2 | 字节3 | 字节4 | 字节5~6 | 字节7 | 字节8 |
|-------|-------|-------|-------|-------|---------|-------|-------|
| 0XA5 | 0X5A | 0xA0 | 0x10 | 0x10 | 0x01 0x00 | Param1 | 校验和 |

- **Param1**：`0x01`-光电设备与干扰设备共用云台且由光电控制；`0x02`-共用云台且由干扰控制；`0x03`-禁用目标与云台联动

**返回帧格式**：见表格 1-1（标准返回帧）

**案例：**

请求：`A5 5A A0 10 10 01 00 01 C2`  
返回：`A5 5A 10 A0 A2 02 00 10 0F 73`

|-------|-------|-------|-------|-------|---------|-------|

|-------|-------|-------|-------|-------|---------|-------|-------|

| 0XA5 | 0X5A | 0x10 | 0xA0 | 0X60 | 参数长(N) | Param1 | 校验和 |

- **Param1**：单个目标信息的 JSON 字符串（UTF8 编码）

**JSON 数据结构：**

| TargetType | int | 目标类型 | 0-图传数据, 1-遥控数据 |
| UniqueID | string | 目标唯一编号 | |
| TargetNo | int | 目标显示编号 | |
| DroneID | string | 无人机ID号 | 仅针对ID破解目标 |
| FreqOrNo | double | 无人机频点(或航迹编号) | 频点 2446.5 / 航迹编号 A1 |
| TargetName | string | 无人机型号 | 如 "Phantom 3/4" |
| WiFiMAC | string | WiFi类无人机MAC地址 | |
| SignalBandWidth | double | 无线电信号带宽 | 仅针对全频频谱探测设备 |
| ModulateMode | int | 调制方式 | 预留 |
| Longitude | double | 无人机经度 | |
| Latitude | double | 无人机纬度 | |
| Altitude | float | 无人机海拔 | |
| Direction | float | 方位 | ° |
| Distance | float | 参考距离 | m |
| Pitch | float | 俯仰 | °(仅针对雷达目标数据) |

| 字节0 | 字节1 | 字节2 | 字节3 | 字节4 | 字节5~6 | 字节7 | 字节8 | 字节9~16 |
|-------|-------|-------|-------|-------|---------|-------|-------|---------|
| 0XA5 | 0X5A | 0xA0 | 0x10 | 0X90 | 参数长(N+11) | Param1 | Param2 | Param3 |

| 字节17 | 字节18~17+N | 字节18+N |
|--------|------------|---------|
| Param4 | Param5 | 校验和 |

**参数说明：**

| 参数 | 类型 | 说明 |
|------|------|------|
| Param1 | byte | 设备类型：0-主动雷达, 1-无线电侦测, 2-光电跟踪, 3-红外, 4-干扰, 6-诱骗, 8-智能控制箱 |
| Param2 | byte | 数据源类型：光电跟踪设备时 — `0x01`-机芯操作, `0x02`-云台操作 |
| Param3 | long (LE) | 设备Id |
| Param4 | byte | 命令类型：`0x00`-回传数据帧, `0x01`-询问数据帧, `0x02`-设置数据帧 |
| Param5 | byte[] | 透传数据包（具体格式查阅各设备协议） |

**案例：**

1. 向右移动：`A5 5A A0 10 90 12 00 02 02 00 00 00 00 00 00 00 00 02 FF 01 00 02 1A 00 1D 91`
2. 询问云台方位及俯仰角：`A5 5A A0 10 90 12 00 02 02 00 00 00 00 00 00 00 00 01 FF 01 00 8D 00 00 8E 72`
3. 回传数据帧1：`A5 5A 10 A0 90 13 00 02 02 00 00 00 00 00 00 00 00 00 FF 01 00 8E 00 00 8C A0 11`
4. 回传数据帧2：`A5 5A 10 A0 90 0C 00 02 02 00 00 00 00 00 00 00 00 00 BB 0B`
